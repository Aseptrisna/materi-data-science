03Membaca Data dari SQLite

SQLite adalah database ringan berbasis satu file (.db), cocok untuk belajar SQL tanpa perlu instalasi server database terpisah.

python
import sqlite3
import pandas as pd

conn = sqlite3.connect("data/raw/toko.db")

# membuat tabel contoh (biasanya database sudah ada, ini hanya demo)
conn.execute("""
    CREATE TABLE IF NOT EXISTS transaksi (
        id INTEGER PRIMARY KEY,
        produk TEXT, jumlah INTEGER, harga INTEGER, tanggal TEXT
    )
""")
conn.execute("INSERT INTO transaksi (produk, jumlah, harga, tanggal) VALUES ('Kopi Susu', 12, 15000, '2026-01-05')")
conn.commit()

df = pd.read_sql_query("SELECT * FROM transaksi", conn)
print(df)
conn.close()

04Query SQL dengan pandas

pd.read_sql_query menerima query SQL apa pun, bukan hanya SELECT * — memungkinkan filtering & agregasi dilakukan langsung di sisi database sebelum data masuk ke Python.

python
conn = sqlite3.connect("data/raw/toko.db")

query = """
    SELECT produk, SUM(jumlah) AS total_jumlah, AVG(harga) AS rata_harga
    FROM transaksi
    WHERE tanggal >= '2026-01-01'
    GROUP BY produk
    ORDER BY total_jumlah DESC
"""
ringkasan = pd.read_sql_query(query, conn)
print(ringkasan)
conn.close()
Kenapa agregasi di SQL?

Untuk database besar, melakukan GROUP BY/WHERE di level SQL jauh lebih efisien daripada menarik seluruh tabel mentah ke pandas lalu memfilternya — database dioptimalkan untuk operasi ini.

05SQLAlchemy sebagai Alternatif

SQLAlchemy menyediakan antarmuka koneksi database yang seragam untuk banyak jenis database (SQLite, PostgreSQL, MySQL, dll), sehingga kode tidak perlu banyak berubah saat database produksi berbeda dari database belajar.

python
from sqlalchemy import create_engine
import pandas as pd

engine = create_engine("sqlite:///data/raw/toko.db")
# untuk PostgreSQL: "postgresql://user:password@host:5432/nama_db"

df = pd.read_sql_query("SELECT * FROM transaksi", engine)
df.to_sql("transaksi_backup", engine, if_exists="replace", index=False)

06Mengambil Data dari REST API

REST API mengembalikan data (biasanya format JSON) lewat permintaan HTTP. Library requests adalah cara standar Python untuk mengakses API.

python
import requests

url = "https://api.exchangerate-api.com/v4/latest/USD"
response = requests.get(url, timeout=10)

print(response.status_code)   # 200 artinya berhasil

data = response.json()        # ubah respons JSON jadi dict Python
print(data["rates"]["IDR"])   # kurs USD ke IDR
Selalu cek status_code

Kode 200 artinya sukses, 404 artinya endpoint tidak ditemukan, 401/403 artinya butuh otentikasi/tidak diizinkan, dan 429 artinya terlalu banyak permintaan (rate limit). Jangan langsung panggil .json() tanpa mengecek status lebih dulu.

07Dari JSON ke DataFrame

Respons API sering berbentuk JSON bersarang (nested). pd.json_normalize meratakan struktur bersarang itu menjadi tabel.

python
import requests
import pandas as pd

data_json = {
    "hasil": [
        {"produk": "Kopi Susu", "detail": {"kategori": "Minuman", "stok": 40}},
        {"produk": "Roti Bakar", "detail": {"kategori": "Makanan", "stok": 15}},
    ]
}

df = pd.json_normalize(data_json["hasil"])
print(df)
#       produk      detail.kategori  detail.stok
# 0  Kopi Susu             Minuman           40
# 1 Roti Bakar             Makanan           15

Notasi detail.kategori terbentuk otomatis dari key bersarang (detail → kategori) sehingga tiap nilai mendapat kolomnya sendiri.

08Dasar Web Scraping

Web scraping mengambil data langsung dari HTML halaman web ketika tidak tersedia API resmi. BeautifulSoup mem-parsing HTML menjadi struktur yang mudah di-query.

python
import requests
from bs4 import BeautifulSoup
import pandas as pd

url = "https://contoh-toko-publik.test/daftar-harga"
response = requests.get(url, headers={"User-Agent": "Mozilla/5.0"}, timeout=10)
soup = BeautifulSoup(response.text, "html.parser")

baris_produk = []
for row in soup.select("table.daftar-harga tr")[1:]:   # [1:] melewati baris header
    kolom = row.find_all("td")
    baris_produk.append({
        "produk": kolom[0].get_text(strip=True),
        "harga": kolom[1].get_text(strip=True),
    })

df_scraping = pd.DataFrame(baris_produk)
print(df_scraping.head())
Cara lebih singkat untuk tabel HTML

Jika data berbentuk tag <table> standar, pd.read_html(url) bisa langsung mengembalikan list DataFrame tanpa perlu BeautifulSoup manual — coba ini dulu sebelum menulis parser sendiri.

09Etika Scraping & robots.txt

Tidak semua halaman boleh di-scrape. Sebelum mengambil data dari situs mana pun, periksa dan patuhi aturan berikut:

  • Cek file https://nama-situs.com/robots.txt — berisi aturan path mana yang boleh/tidak boleh diakses oleh bot.
  • Baca Syarat & Ketentuan (Terms of Service) situs — sebagian situs melarang scraping secara eksplisit.
  • Jangan membebani server: beri jeda antar-request (time.sleep()), jangan scraping ribuan halaman dalam hitungan detik.
  • Jangan scraping data pribadi/sensitif atau konten berhak cipta untuk disebarluaskan ulang tanpa izin.
  • Utamakan API resmi jika tersedia — scraping adalah solusi terakhir, bukan solusi pertama.
Scraping untuk tugas kuliah

Gunakan scraping hanya pada situs yang mengizinkan (cek robots.txt), atau situs demo/sandbox yang memang disediakan untuk latihan. Jangan jalankan scraping ke situs produksi tanpa izin pemiliknya.

10Menggabungkan Data: concat

pd.concat menumpuk beberapa DataFrame menjadi satu, baik secara vertikal (menambah baris) maupun horizontal (menambah kolom).

python
df_sql = pd.DataFrame({"produk": ["Kopi Susu"], "jumlah": [12]})
df_api = pd.DataFrame({"produk": ["Es Teh"], "jumlah": [15]})

gabungan_vertikal = pd.concat([df_sql, df_api], ignore_index=True)
# ignore_index=True membuat index baru 0,1,2,... alih-alih mengulang index asal

11Menggabungkan Data: merge/join

pd.merge menggabungkan dua DataFrame berdasarkan kolom kunci yang sama (mirip JOIN di SQL). Empat jenis merge yang paling sering dipakai:

JenisHasilKapan dipakai
innerHanya baris yang kuncinya cocok di kedua tabelHanya butuh data yang lengkap di kedua sisi
leftSemua baris tabel kiri + data tabel kanan jika cocokTabel kiri adalah data utama (misal transaksi)
rightSemua baris tabel kanan + data tabel kiri jika cocokKebalikan dari left
outerSemua baris dari kedua tabel, isi kosong jika tak cocokIngin melihat semua data termasuk yang tidak lengkap
python
transaksi = pd.DataFrame({
    "produk_id": [1, 2, 3],
    "jumlah": [12, 8, 15],
})
produk_master = pd.DataFrame({
    "produk_id": [1, 2, 4],
    "nama_produk": ["Kopi Susu", "Roti Bakar", "Donat"],
})

hasil_inner = pd.merge(transaksi, produk_master, on="produk_id", how="inner")
# hanya produk_id 1 dan 2 (3 & 4 hilang karena tidak cocok di kedua tabel)

hasil_left = pd.merge(transaksi, produk_master, on="produk_id", how="left")
# semua baris transaksi (1,2,3) dipertahankan; produk_id 3 -> nama_produk jadi NaN

print(hasil_left)
merge vs join

df.join() adalah jalan pintas untuk menggabungkan berdasarkan index (bukan kolom biasa), sedangkan pd.merge() lebih fleksibel karena bisa menggabungkan berdasarkan kolom kunci apa pun lewat parameter on.

12Menyimpan ke data/processed

python
data_gabungan = pd.merge(transaksi, produk_master, on="produk_id", how="left")
data_gabungan.to_csv("data/processed/transaksi_gabungan.csv", index=False)
Tanda berhasil

Jumlah baris file hasil gabungan sesuai jenis how yang dipilih (misalnya left menghasilkan jumlah baris sama persis dengan tabel kiri), dan kolom dari kedua tabel asal semuanya muncul.

13Latihan

  1. Buat database SQLite toko.db berisi tabel transaksi dengan minimal 5 baris, lalu ambil ringkasan total jumlah per produk memakai pd.read_sql_query.
  2. Ambil data dari satu API publik gratis pilihanmu (misalnya API kurs mata uang atau API cuaca), ubah hasil JSON-nya menjadi DataFrame memakai pd.json_normalize.
  3. Cari satu halaman web publik yang mengizinkan scraping (cek robots.txt-nya terlebih dahulu), ambil satu tabel sederhana dengan pd.read_html atau BeautifulSoup.
  4. Gabungkan ketiga hasil data di atas (SQL, API, scraping) menjadi satu DataFrame memakai concat/merge sesuai konteksnya, lalu simpan ke data/processed/gabungan_pertemuan4.csv.
