01Tujuan & Prasyarat

Di akhir pertemuan ini, mahasiswa dapat menjelaskan posisi data science dalam organisasi, memiliki environment Python yang siap pakai, dan berhasil membaca dataset pertama menggunakan pandas di Jupyter Notebook.

  • Laptop dengan minimal 4GB RAM (8GB lebih nyaman untuk library seperti scikit-learn/pandas dengan dataset menengah).
  • Koneksi internet untuk mengunduh Python, Anaconda, dan package.
  • Tidak wajib sudah bisa Python — dasar Python untuk data science akan direview di Pertemuan 2. Yang penting sudah pernah menulis kode apa pun (hasil mata kuliah pemrograman sebelumnya).

02Apa itu Data Science

Data Science adalah disiplin yang menggabungkan statistik, pemrograman, dan pengetahuan domain untuk mengubah data mentah menjadi insight, prediksi, atau keputusan yang bisa ditindaklanjuti. Bukan sekadar "main data" — tujuan akhirnya selalu menjawab pertanyaan bisnis atau ilmiah yang konkret.

Tiga pilar yang membentuk data science sering digambarkan sebagai irisan tiga lingkaran:

  • Matematika & Statistika — memahami distribusi data, ketidakpastian, dan validitas kesimpulan.
  • Pemrograman & Rekayasa — mengolah data dalam jumlah besar secara efisien dan reproducible.
  • Pengetahuan Domain — tanpa ini, model secanggih apa pun bisa salah arah karena tidak paham konteks bisnis/datanya.
Contoh kasus nyata

Sebuah minimarket ingin tahu kenapa penjualan turun di cabang tertentu. Data scientist tidak langsung membuat model machine learning rumit — ia mulai dari EDA (Pertemuan 6) untuk melihat pola, baru menentukan apakah masalahnya butuh model prediktif atau cukup insight deskriptif.

03Peran: Data Scientist vs Analyst vs Engineer

Empat peran ini sering tertukar di lapangan, padahal fokus kerjanya berbeda:

PeranFokus utamaOutput khas
Data AnalystAnalisis deskriptif & reportingDashboard, laporan tren, rekomendasi bisnis
Data ScientistAnalisis + model prediktif/statistikModel ML, eksperimen, insight berbasis data
Data EngineerPipeline & infrastruktur dataETL, data warehouse, data siap pakai
ML EngineerProduksi-kan model MLModel yang di-deploy, API prediksi, monitoring

Sepanjang semester ini, kita akan menyentuh keempat peran tersebut secara ringan: mengumpulkan & membersihkan data (mirip Data Engineer di Pertemuan 4-5), menganalisis & membangun model (inti Data Scientist di Pertemuan 6-14), sampai men-deploy model sederhana (mirip ML Engineer di Pertemuan 15).

05Instalasi Python & Anaconda

Kita memakai Anaconda (atau versi ringannya, Miniconda) karena sudah menyertakan Python, pengelola environment (conda), dan sebagian besar library data science umum dalam satu paket instalasi.

  1. Unduh installer sesuai OS dari situs resmi Anaconda/Miniconda.
  2. Jalankan installer, centang opsi "Add to PATH" jika ditawarkan (memudahkan akses dari terminal).
  3. Verifikasi instalasi:
verifikasi instalasi
python --version
# Python 3.11.x atau lebih baru

conda --version
# conda 23.x.x
Tidak mau pakai Anaconda?

Boleh pakai Python resmi dari python.org + venv bawaan. Semua contoh kode di materi ini tetap jalan, hanya perintah pembuatan environment di bagian 06 yang sedikit berbeda (sudah disertakan kedua versinya).

06Virtual Environment

Virtual environment mengisolasi dependency tiap proyek, supaya versi library di satu mata kuliah tidak bentrok dengan proyek lain di laptop yang sama.

dengan conda
conda create -n datasci python=3.11 -y
conda activate datasci
alternatif: venv bawaan Python
python -m venv .venv

# aktifkan (macOS/Linux)
source .venv/bin/activate

# aktifkan (Windows PowerShell)
.venv\Scripts\Activate.ps1
Tanda environment aktif

Prompt terminal menampilkan nama environment di depan, misalnya (datasci) user@laptop ~ %. Semua perintah pip install setelah ini hanya berlaku di dalam environment tersebut.

07Jupyter Notebook / JupyterLab

Jupyter adalah lingkungan kerja interaktif berbasis sel (cell) — kode, hasil eksekusi, visualisasi, dan catatan markdown bisa digabung dalam satu dokumen. Ini adalah alat yang paling sering dipakai data scientist untuk eksplorasi.

terminal
pip install jupyterlab
jupyter lab

Perintah di atas membuka JupyterLab di browser. Buat notebook baru (File → New → Notebook), lalu coba sel pertama:

sel notebook
print("Halo, Data Science!")
2 + 2

Jalankan sel dengan Shift+Enter. Hasil dari baris terakhir (2 + 2) akan tampil otomatis di bawah sel tanpa perlu print() — kebiasaan khas notebook yang berbeda dari menjalankan skrip .py biasa.

08VS Code untuk Data Science

VS Code bisa menjalankan notebook (.ipynb) langsung tanpa membuka browser, dengan ekstensi berikut:

  • Python (Microsoft) — linting, IntelliSense, menjalankan file .py.
  • Jupyter (Microsoft) — membuka & menjalankan file .ipynb di dalam VS Code.

Setelah ekstensi terpasang, buka folder proyek, buat file baru dengan ekstensi .ipynb, lalu pilih kernel Python sesuai environment yang sudah dibuat di bagian 06 (klik "Select Kernel" di pojok kanan atas).

09pip & requirements.txt

pip adalah package manager Python untuk menginstal library. Praktik standar: catat semua dependency proyek di requirements.txt supaya proyek bisa direproduksi oleh orang lain (atau laptop lain).

terminal
pip install pandas numpy matplotlib seaborn scikit-learn jupyterlab

# simpan daftar dependency terpasang
pip freeze > requirements.txt

# di laptop lain, install ulang persis sama
pip install -r requirements.txt

11Struktur Proyek Data Science

Sejak pertemuan ini, biasakan menata folder proyek secara konsisten supaya notebook tidak bercampur dengan data mentah dan kode yang bisa dipakai ulang:

struktur folder
proyek-data-science/
├── data/
│   ├── raw/              data mentah, JANGAN diubah langsung
│   └── processed/        hasil data yang sudah dibersihkan
├── notebooks/
│   └── 01-eksplorasi.ipynb
├── src/                   fungsi python yang dipakai ulang antar notebook
├── requirements.txt
└── README.md
Kenapa data/raw tidak boleh diubah?

Supaya proses pembersihan data selalu bisa diulang dari titik awal yang sama (reproducibility) — prinsip penting yang akan terus ditekankan sampai proyek akhir di Pertemuan 16.

12Hello Data: Dataset Pertama dengan pandas

Saatnya membuktikan environment sudah siap. Buat berkas data/raw/penjualan.csv sederhana:

data/raw/penjualan.csv
tanggal,produk,kategori,jumlah,harga
2026-01-05,Kopi Susu,Minuman,12,15000
2026-01-05,Roti Bakar,Makanan,8,12000
2026-01-06,Kopi Susu,Minuman,20,15000
2026-01-06,Es Teh,Minuman,15,8000
2026-01-07,Roti Bakar,Makanan,10,12000

Lalu buka notebook baru di notebooks/01-eksplorasi.ipynb, dan jalankan:

notebooks/01-eksplorasi.ipynb
import pandas as pd

df = pd.read_csv("../data/raw/penjualan.csv")
df.head()

Jika berhasil, akan muncul tabel 5 baris pertama. Coba juga perintah eksplorasi dasar:

df.info()          # tipe data tiap kolom & jumlah baris
df.describe()      # ringkasan statistik kolom numerik
df["kategori"].unique()   # nilai unik di kolom kategori
Tanda berhasil

df.info() menampilkan 5 kolom dengan tipe data yang masuk akal (object untuk teks, int64/float64 untuk angka), dan tidak ada error FileNotFoundError atau ModuleNotFoundError.

Error ModuleNotFoundError: No module named 'pandas'

Kernel Jupyter yang dipilih bukan environment yang sudah di-pip install pandas. Cek kembali bagian 06-08: pastikan environment aktif saat menjalankan pip install, dan kernel notebook mengarah ke environment yang sama.

13Latihan

  1. Pastikan python --version, jupyter lab, dan import pandas, numpy, matplotlib, scikit-learn semuanya berjalan tanpa error di environment datasci.
  2. Tambahkan 5 baris data baru ke penjualan.csv (boleh produk/kategori buatan sendiri), lalu jalankan ulang df.head(), df.info(), dan df.describe() untuk melihat perubahannya.
  3. Buat README.md singkat di folder proyekmu berisi: nama, environment yang dipakai (conda/venv), dan cara menjalankan notebook.
  4. Simpan struktur folder sesuai bagian 11 — ini akan dipakai terus sampai proyek akhir UAS di Pertemuan 16.
