02Series: Array Berlabel

Series adalah struktur data 1 dimensi di pandas, mirip ndarray NumPy tapi setiap elemennya punya label index. Series adalah "satu kolom" dari sebuah DataFrame.

python
import pandas as pd

harga = pd.Series([15000, 12000, 8000], index=["Kopi Susu", "Roti Bakar", "Es Teh"])
print(harga)
# Kopi Susu     15000
# Roti Bakar    12000
# Es Teh         8000
# dtype: int64

print(harga["Roti Bakar"])   # 12000 - akses lewat label
print(harga.mean())           # 11666.67 - fungsi agregasi seperti NumPy

03DataFrame: Tabel Berlabel

DataFrame adalah struktur data 2 dimensi — tabel dengan baris & kolom berlabel, di mana setiap kolom pada dasarnya adalah sebuah Series. Ini adalah struktur data paling sering dipakai sepanjang mata kuliah ini.

IstilahAnalogi spreadsheet
DataFrameSeluruh sheet/tabel
Kolom (Series)Satu kolom tabel
IndexNomor baris di paling kiri
dtypesTipe data tiap kolom (angka, teks, tanggal, dll)

04Membuat DataFrame dari Dict & List

python
import pandas as pd

# dari dict: key jadi nama kolom
data = {
    "produk": ["Kopi Susu", "Roti Bakar", "Es Teh", "Kopi Susu"],
    "kategori": ["Minuman", "Makanan", "Minuman", "Minuman"],
    "jumlah": [12, 8, 15, 20],
    "harga": [15000, 12000, 8000, 15000],

df = pd.DataFrame(data)

# dari list of dict: tiap dict jadi satu baris
data_list = [
    {"produk": "Kopi Susu", "jumlah": 12, "harga": 15000},

]

07Indexing: loc & iloc

.loc mengakses data berdasarkan label (nama kolom/index), sedangkan .iloc berdasarkan posisi integer (seperti index list).

python
print(df.loc[0])                      # baris dengan label index 0
print(df.loc[0, "produk"])            # "Kopi Susu"
print(df.loc[0:2, ["produk", "harga"]])  # baris 0-2, kolom tertentu (inklusif!)

print(df.iloc[0])                      # baris pertama (posisi 0)
print(df.iloc[0, 0])                   # elemen baris 0, kolom 0
print(df.iloc[0:2, 0:2])              # baris 0-1, kolom 0-1 (eksklusif di akhir)
Perbedaan penting

.loc[0:2] menyertakan baris dengan label 2 (inklusif), sementara .iloc[0:2] mengikuti aturan slicing Python biasa (eksklusif di akhir, jadi hanya mengambil posisi 0 dan 1).

08Filtering Kondisional

Filtering di pandas memakai boolean indexing: ekspresi kondisi menghasilkan Series berisi True/False, lalu dipakai sebagai "mask" untuk memilih baris.

python
minuman = df[df["kategori"] == "Minuman"]
laris = df[df["jumlah"] > 10]

# kombinasi kondisi: & (dan), | (atau) - WAJIB pakai tanda kurung per kondisi
minuman_laris = df[(df["kategori"] == "Minuman") & (df["jumlah"] > 10)]
murah_atau_laris = df[(df["harga"] < 10000) | (df["jumlah"] > 15)]

print(minuman_laris[["produk", "jumlah"]])
Error ValueError: truth value of a Series is ambiguous

Muncul kalau memakai and/or Python biasa alih-alih &/|, atau lupa memberi tanda kurung di setiap kondisi gabungan. Selalu tulis (kondisi1) & (kondisi2), bukan kondisi1 & kondisi2 tanpa kurung.

09Menambah & Menghapus Kolom

python
df["total"] = df["jumlah"] * df["harga"]              # kolom baru dari operasi kolom lain
df["kategori_singkat"] = df["kategori"].str[:3]        # ambil 3 huruf pertama

df = df.drop(columns=["kategori_singkat"])             # hapus satu kolom
df = df.drop(columns=["total", "harga"], errors="ignore")  # hapus beberapa, aman jika tak ada

print(df.columns.tolist())
Tips

drop secara default mengembalikan DataFrame baru, bukan mengubah df di tempat. Tambahkan inplace=True atau timpa ulang (df = df.drop(...)) agar perubahan tersimpan.

11Groupby & Agregasi

groupby mengimplementasikan pola split-apply-combine: data dipecah berdasarkan kategori, fungsi agregasi diterapkan per kelompok, lalu hasilnya digabung kembali jadi satu tabel ringkas.

python
ringkasan = df.groupby("kategori")["jumlah"].sum()
print(ringkasan)
# kategori
# Makanan      8
# Minuman     47

ringkasan_lengkap = df.groupby("kategori").agg(
    total_jumlah=("jumlah", "sum"),
    rata_rata_harga=("harga", "mean"),
    jumlah_produk=("produk", "count"),
).reset_index()

print(ringkasan_lengkap)
Kenapa .reset_index()?

Hasil groupby menjadikan kolom pengelompokan (kategori) sebagai index, bukan kolom biasa. .reset_index() mengembalikannya menjadi kolom normal, memudahkan filtering/sorting lanjutan.

python
ringkasan_lengkap.to_csv("data/processed/ringkasan_kategori.csv", index=False)

Tanda berhasil

File muncul di data/processed/ringkasan_kategori.csv dan ketika dibuka ulang dengan pd.read_csv(...) jumlah baris & kolomnya sesuai ekspektasi, tanpa kolom tambahan bernama Unnamed: 0.

13Studi Kasus Mini: Ringkasan Penjualan

Menggabungkan semua teknik di atas dalam satu alur kerja singkat:

python
import pandas as pd

df = pd.read_csv("data/raw/penjualan.csv")
df["total"] = df["jumlah"] * df["harga"]

produk_terlaris = (
    df.groupby("produk")
    .agg(total_terjual=("jumlah", "sum"), total_pendapatan=("total", "sum"))
    .reset_index()
    .sort_values("total_pendapatan", ascending=False)
)

print(produk_terlaris.head(3))
produk_terlaris.to_csv("data/processed/produk_terlaris.csv", index=False)
