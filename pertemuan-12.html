01Tujuan & Prasyarat

Di akhir pertemuan ini, mahasiswa dapat membedakan supervised dan unsupervised learning, mengelompokkan data dengan K-Means, menentukan jumlah cluster optimal dengan Elbow Method dan Silhouette Score, serta mereduksi dimensi data berdimensi tinggi dengan PCA untuk keperluan visualisasi.

  • Sudah familiar dengan pandas, matplotlib, dan alur dasar scikit-learn (fit, transform, predict) dari Pertemuan 9-11.
  • Memahami konsep scaling/normalisasi data numerik (akan direview singkat di bagian 05).

02Supervised vs Unsupervised Learning

Sampai Pertemuan 11, seluruh model yang kita latih adalah supervised learning — data punya label jawaban (y) yang ingin diprediksi, misalnya "sakit/sehat" atau harga rumah. Unsupervised learning bekerja tanpa label sama sekali: model hanya diberi fitur (X) dan harus menemukan struktur atau pola tersembunyi sendiri.

AspekSupervisedUnsupervised
DataPunya label (X, y)Hanya fitur (X)
TujuanMemprediksi label baruMenemukan struktur/pola (cluster, dimensi penting)
EvaluasiAccuracy, F1, RMSE (bandingkan dengan label aktual)Silhouette score, inertia (tidak ada "jawaban benar" untuk dibandingkan)
Contoh algoritmaLogistic Regression, Decision Tree, KNNK-Means, PCA, Hierarchical Clustering
Contoh kasus nyata

Sebuah minimarket punya data transaksi pelanggan tapi tidak tahu "segmen pelanggan" apa saja yang ada. Tidak ada label siap pakai seperti "pelanggan hemat" atau "pelanggan loyal" — unsupervised learning membantu menemukan segmen tersebut dari pola belanja.

03Dataset Contoh: Segmentasi Pelanggan

Sepanjang pertemuan ini kita memakai dataset buatan sendiri: data pelanggan minimarket dengan dua fitur utama, frekuensi belanja per bulan dan rata-rata nilai belanja (dalam ribuan rupiah), agar hasil cluster mudah divisualisasikan dalam 2D.

notebooks/12-clustering-pca.ipynb
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.datasets import make_blobs

X, _ = make_blobs(
    n_samples=300, centers=4, cluster_std=0.9, random_state=42
)
df = pd.DataFrame(X, columns=["frekuensi_belanja_z", "rata_nilai_belanja_z"])

plt.scatter(df["frekuensi_belanja_z"], df["rata_nilai_belanja_z"], s=20)
plt.xlabel("Frekuensi belanja per bulan (standardized)")
plt.ylabel("Rata-rata nilai belanja (standardized)")
plt.title("Sebaran Pelanggan Sebelum Clustering")
plt.show()

Data sudah dalam bentuk standardized (hasil scaling) agar fokus pembelajaran ada di algoritma clustering-nya. Pada bagian 13, kita akan memulai dari data mentah (sebelum scaling) untuk melihat pipeline lengkapnya.

04Konsep K-Means Clustering

K-Means mengelompokkan data menjadi k cluster berdasarkan kedekatan jarak ke pusat cluster (centroid). Algoritmanya bekerja secara iteratif:

  1. Inisialisasi — pilih k titik sebagai centroid awal (scikit-learn memakai metode k-means++ secara default, yang memilih centroid awal secara cerdas agar saling berjauhan, bukan benar-benar acak).
  2. Assignment — tiap titik data ditugaskan ke centroid terdekat (berdasarkan jarak Euclidean).
  3. Update — tiap centroid dipindahkan ke rata-rata posisi semua titik yang ditugaskan padanya.
  4. Ulangi langkah 2-3 sampai penugasan titik ke cluster tidak lagi berubah (konvergen) atau mencapai iterasi maksimum.
Kenapa harus menentukan k di awal?

Berbeda dari klasifikasi yang jumlah kelasnya sudah pasti dari label, K-Means mengharuskan kita menentukan jumlah cluster k sebelum menjalankan algoritma — inilah kenapa Elbow Method dan Silhouette Score (bagian 06-07) penting.

05K-Means dengan scikit-learn

python
from sklearn.cluster import KMeans

kmeans = KMeans(n_clusters=4, init="k-means++", n_init=10, random_state=42)
labels = kmeans.fit_predict(df[["frekuensi_belanja_z", "rata_nilai_belanja_z"]])

df["cluster"] = labels
print(df["cluster"].value_counts())
print("Koordinat centroid:\n", kmeans.cluster_centers_)
Tanda berhasil

df["cluster"] berisi label integer dari 0 sampai n_clusters - 1, dan kmeans.cluster_centers_ berbentuk array dengan baris sebanyak n_clusters dan kolom sebanyak jumlah fitur.

06Elbow Method

Inertia (kmeans.inertia_) mengukur total jarak kuadrat tiap titik ke centroid terdekatnya — semakin kecil, semakin rapat cluster-nya. Inertia selalu menurun seiring k bertambah, tapi penurunannya melambat setelah titik tertentu. Elbow Method mencari titik "siku" di mana penurunan mulai melandai.

python
inertias = []
k_range = range(1, 11)

for k in k_range:
    km = KMeans(n_clusters=k, n_init=10, random_state=42)
    km.fit(df[["frekuensi_belanja_z", "rata_nilai_belanja_z"]])
    inertias.append(km.inertia_)

plt.plot(k_range, inertias, marker="o")
plt.xlabel("Jumlah cluster (k)")
plt.ylabel("Inertia")
plt.title("Elbow Method")
plt.show()

Pada dataset contoh ini (dibuat dari 4 pusat blob), grafik biasanya menunjukkan penurunan tajam sampai k=4, lalu melandai — menandakan k=4 adalah pilihan yang wajar.

07Silhouette Score

Elbow Method kadang ambigu karena "siku" tidak selalu jelas. Silhouette Score memberi ukuran kuantitatif per nilai k: seberapa mirip suatu titik dengan cluster-nya sendiri dibanding cluster terdekat lainnya. Rentang nilainya -1 sampai 1 — semakin mendekati 1, semakin baik pemisahan antar cluster.

python
from sklearn.metrics import silhouette_score

sil_scores = []
k_range_sil = range(2, 11)  # minimal 2 cluster

for k in k_range_sil:
    km = KMeans(n_clusters=k, n_init=10, random_state=42)
    labels_k = km.fit_predict(df[["frekuensi_belanja_z", "rata_nilai_belanja_z"]])
    sil_scores.append(silhouette_score(df[["frekuensi_belanja_z", "rata_nilai_belanja_z"]], labels_k))

plt.plot(k_range_sil, sil_scores, marker="o", color="green")
plt.xlabel("Jumlah cluster (k)")
plt.ylabel("Silhouette Score")
plt.title("Silhouette Score per k")
plt.show()

best_k = k_range_sil[np.argmax(sil_scores)]
print("k optimal menurut silhouette score:", best_k)
Elbow vs Silhouette

Gunakan keduanya sebagai pelengkap: Elbow Method cepat dihitung dan memberi gambaran kasar, Silhouette Score lebih presisi tapi lebih mahal secara komputasi untuk dataset besar.

09Interpretasi & Profiling Cluster

Angka cluster (0, 1, 2, 3) sendiri tidak bermakna bisnis — langkah selanjutnya adalah profiling: melihat karakteristik rata-rata tiap cluster untuk memberi nama/insight yang bisa ditindaklanjuti.

python
profil = df.groupby("cluster")[["frekuensi_belanja_z", "rata_nilai_belanja_z"]].mean()
print(profil)

# Misal hasil interpretasi:
# cluster 0 -> frekuensi rendah, nilai belanja rendah   -> "Pelanggan pasif"
# cluster 1 -> frekuensi tinggi, nilai belanja tinggi    -> "Pelanggan loyal bernilai tinggi"
# cluster 2 -> frekuensi tinggi, nilai belanja rendah    -> "Pelanggan sering tapi hemat"
# cluster 3 -> frekuensi rendah, nilai belanja tinggi    -> "Pelanggan sesekali tapi besar"
Ini bagian paling penting bagi bisnis

Algoritma hanya memberi pengelompokan angka — nilai bisnisnya muncul saat tim data science menerjemahkan tiap cluster menjadi strategi konkret, misalnya promo berbeda untuk "Pelanggan pasif" vs "Pelanggan loyal".

10Konsep Principal Component Analysis

PCA (Principal Component Analysis) adalah teknik reduksi dimensi: mengubah banyak fitur yang saling berkorelasi menjadi sedikit fitur baru (principal component) yang tetap mempertahankan sebanyak mungkin variasi/informasi dari data asli. Komponen pertama menangkap arah dengan variasi terbesar, komponen kedua menangkap variasi terbesar berikutnya yang tegak lurus komponen pertama, dan seterusnya.

Kenapa berguna untuk visualisasi?

Data dunia nyata sering punya puluhan fitur (misalnya 20 kolom survei pelanggan) — mustahil divisualisasikan langsung. PCA memampatkan informasi itu menjadi 2 komponen utama sehingga bisa diplot sebagai scatter plot 2D, sambil tetap mempertahankan pola/struktur terpenting data.

11PCA dengan scikit-learn

Untuk mendemonstrasikan PCA secara bermakna, kita perlu dataset berdimensi lebih tinggi. Kita perluas dataset pelanggan menjadi 5 fitur numerik:

python
from sklearn.datasets import make_blobs
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA

X5, y_true = make_blobs(n_samples=300, centers=4, n_features=5, cluster_std=1.3, random_state=42)
df5 = pd.DataFrame(X5, columns=[f"fitur_{i+1}" for i in range(5)])

scaler = StandardScaler()
X5_scaled = scaler.fit_transform(df5)

pca = PCA(n_components=2, random_state=42)
X5_pca = pca.fit_transform(X5_scaled)

df5["pc1"] = X5_pca[:, 0]
df5["pc2"] = X5_pca[:, 1]
print(df5[["pc1", "pc2"]].head())
Jangan lupa scaling sebelum PCA

PCA sensitif terhadap skala fitur — fitur dengan rentang nilai besar akan mendominasi komponen utama meskipun secara substansi tidak lebih penting. Selalu StandardScaler dulu sebelum PCA.

12Explained Variance Ratio

explained_variance_ratio_ menunjukkan proporsi variasi data asli yang berhasil dipertahankan oleh tiap komponen utama. Menjumlahkan beberapa komponen pertama memberi gambaran seberapa banyak informasi "hilang" akibat reduksi dimensi.

python
print("Explained variance ratio per komponen:", pca.explained_variance_ratio_)
print("Total variasi dipertahankan (2 komponen):", pca.explained_variance_ratio_.sum())

plt.scatter(df5["pc1"], df5["pc2"], c=y_true, cmap="viridis", s=25)
plt.xlabel(f"PC1 ({pca.explained_variance_ratio_[0]*100:.1f}% variasi)")
plt.ylabel(f"PC2 ({pca.explained_variance_ratio_[1]*100:.1f}% variasi)")
plt.title("Visualisasi Data 5 Fitur dalam 2 Dimensi (PCA)")
plt.show()
Tanda hasil masuk akal

Jika dua komponen pertama berhasil mempertahankan di atas 70-80% total variasi, scatter plot 2D-nya sudah cukup representatif untuk menggambarkan struktur data asli berdimensi lebih tinggi.

13Pipeline: Scaling → PCA → KMeans

Alur lengkap yang paling umum dipakai di industri menggabungkan ketiga teknik di atas secara berurutan: scaling menyamakan skala fitur, PCA mereduksi dimensi (sekaligus mengurangi noise), lalu KMeans mengelompokkan data pada ruang berdimensi rendah hasil PCA.

python
from sklearn.pipeline import Pipeline

pipeline = Pipeline([
    ("scaler", StandardScaler()),
    ("pca", PCA(n_components=2, random_state=42)),
    ("kmeans", KMeans(n_clusters=4, n_init=10, random_state=42)),
])

df5["cluster"] = pipeline.fit_predict(df5[[f"fitur_{i+1}" for i in range(5)]])

X_pca_result = pipeline.named_steps["pca"].transform(
    pipeline.named_steps["scaler"].transform(df5[[f"fitur_{i+1}" for i in range(5)]])
)

plt.scatter(X_pca_result[:, 0], X_pca_result[:, 1], c=df5["cluster"], cmap="tab10", s=25)
plt.xlabel("PC1")
plt.ylabel("PC2")
plt.title("Pipeline Scaling -> PCA -> KMeans")
plt.show()
Keuntungan memakai Pipeline

Seluruh langkah (scaling, PCA, clustering) tergabung dalam satu objek yang konsisten diterapkan — mengurangi risiko lupa men-scale data baru dengan parameter yang sama. Pipeline scikit-learn akan dibahas lebih dalam di Pertemuan 13.
