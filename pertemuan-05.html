01Tujuan & Prasyarat

Di akhir pertemuan ini, mahasiswa dapat mendeteksi dan menangani missing value, duplikat, serta outlier; mengonversi tipe data yang salah; dan menyiapkan kolom kategorikal & numerik agar siap dipakai model machine learning di Pertemuan 9 ke depan.

  • Sudah menyelesaikan Pertemuan 2-4 (NumPy, pandas, pengumpulan data).
  • Install dependency tambahan: pip install scikit-learn matplotlib seaborn.

02Kenapa Data Cleaning Memakan Waktu Paling Besar

Survei industri berulang kali menunjukkan data scientist menghabiskan 60-80% waktu proyek untuk membersihkan & mempersiapkan data, bukan membangun model. Model machine learning secanggih apa pun akan menghasilkan kesimpulan yang salah jika data yang dimasukkan kotor — prinsip yang dikenal sebagai "garbage in, garbage out".

Contoh nyata

Dataset penjualan UMKM sering punya kolom tanggal dengan format campur (05/01/2026 dan 2026-01-05 dalam file yang sama), harga bertipe teks karena ada simbol "Rp", serta entri ganda akibat input manual kasir dua kali untuk transaksi yang sama.

03Mendeteksi Missing Values

python
import pandas as pd
import numpy as np

df = pd.DataFrame({
    "produk": ["Kopi Susu", "Roti Bakar", None, "Es Teh", "Kopi Susu"],
    "jumlah": [12, np.nan, 15, 20, 12],
    "harga": [15000, 12000, 8000, np.nan, 15000],
})

print(df.isna())            # tabel True/False tiap sel
print(df.isna().sum())      # jumlah missing value per kolom
print(df.isna().sum().sum())   # total seluruh missing value di DataFrame
print(df.isnull().mean() * 100)   # persentase missing per kolom
isna() vs isnull()

Keduanya identik di pandas — isnull() adalah alias dari isna(), disediakan untuk kenyamanan penulisan karena pengguna R/SQL lebih familiar dengan istilah "null".

04Menangani Missing Values

Dua strategi utama: menghapus baris/kolom bermasalah (dropna), atau mengisi nilai yang hilang dengan nilai pengganti (fillna).

python
# dropna: hapus baris yang punya missing value di kolom manapun
df_bersih = df.dropna()

# hapus hanya jika SEMUA kolom di baris itu kosong
df_bersih2 = df.dropna(how="all")

# hapus kolom jika lebih dari 50% isinya missing
df_bersih3 = df.dropna(axis=1, thresh=len(df) * 0.5)

# fillna dengan nilai statistik
df["jumlah"] = df["jumlah"].fillna(df["jumlah"].median())      # median: tahan outlier
df["harga"] = df["harga"].fillna(df["harga"].mean())            # mean: data numerik normal
df["produk"] = df["produk"].fillna(df["produk"].mode()[0])      # modus: data kategorikal

# fillna dengan nilai sebelumnya/berikutnya (cocok untuk data deret waktu)
df_ffill = df.fillna(method="ffill")   # forward fill: isi dengan nilai sebelumnya
df_bfill = df.fillna(method="bfill")   # backward fill: isi dengan nilai sesudahnya
StrategiKapan cocok dipakai
dropnaMissing value sedikit (<5%) dan baris lain informatif lengkap
MeanKolom numerik dengan distribusi relatif normal, tanpa outlier ekstrem
MedianKolom numerik dengan outlier/distribusi miring (skewed)
ModusKolom kategorikal (teks)
ffill / bfillData deret waktu, di mana nilai terdekat masuk akal sebagai pengganti
Jangan asal pilih mean

Mengisi missing value dengan mean() pada kolom yang punya outlier ekstrem (misalnya satu transaksi senilai 50 juta di antara transaksi normal puluhan ribu) akan menghasilkan nilai pengganti yang tidak representatif. Cek distribusi dulu dengan df[kolom].hist() sebelum memutuskan.

05Mendeteksi & Menangani Duplikat

python
print(df.duplicated())          # True/False tiap baris (True jika duplikat baris sebelumnya)
print(df.duplicated().sum())    # total baris duplikat

df_unik = df.drop_duplicates()                       # hapus duplikat persis (semua kolom sama)
df_unik2 = df.drop_duplicates(subset=["produk"])       # anggap duplikat jika kolom "produk" sama
df_unik3 = df.drop_duplicates(keep="last")             # simpan kemunculan terakhir, bukan pertama
Tanda berhasil

df.duplicated().sum() menghasilkan 0 setelah drop_duplicates() dijalankan, dan jumlah baris (df.shape[0]) berkurang sesuai jumlah duplikat yang terdeteksi sebelumnya.

06Deteksi Outlier dengan IQR

IQR (Interquartile Range) adalah selisih antara kuartil 3 (Q3, persentil 75) dan kuartil 1 (Q1, persentil 25). Nilai di luar Q1 - 1.5*IQR sampai Q3 + 1.5*IQR dianggap outlier.

python
Q1 = df["jumlah"].quantile(0.25)
Q3 = df["jumlah"].quantile(0.75)
IQR = Q3 - Q1

batas_bawah = Q1 - 1.5 * IQR
batas_atas = Q3 + 1.5 * IQR

outlier_iqr = df[(df["jumlah"] < batas_bawah) | (df["jumlah"] > batas_atas)]
df_tanpa_outlier = df[(df["jumlah"] >= batas_bawah) & (df["jumlah"] <= batas_atas)]

print(f"Batas normal: {batas_bawah:.1f} - {batas_atas:.1f}")
print(f"Jumlah outlier terdeteksi: {len(outlier_iqr)}")

07Deteksi Outlier dengan Z-score & Visualisasi Boxplot

Z-score mengukur berapa standar deviasi suatu nilai menyimpang dari rata-rata. Umumnya, |z| > 3 dianggap outlier.

python
from scipy import stats
import numpy as np

z_scores = np.abs(stats.zscore(df["jumlah"].dropna()))
outlier_zscore = df.loc[df["jumlah"].dropna().index][z_scores > 3]

print(outlier_zscore)
visualisasi boxplot
import matplotlib.pyplot as plt
import seaborn as sns

fig, ax = plt.subplots(figsize=(6, 4))
sns.boxplot(x=df["jumlah"], ax=ax, color="#3659D9")
ax.set_title("Boxplot Jumlah Terjual — Deteksi Outlier")
plt.tight_layout()
plt.savefig("boxplot_jumlah.png")
plt.show()
Membaca boxplot

Kotak (box) menunjukkan rentang Q1-Q3 (IQR), garis tengah adalah median, "kumis" (whisker) menjangkau sampai 1.5×IQR, dan titik-titik di luar kumis adalah outlier — representasi visual langsung dari rumus IQR di bagian sebelumnya.

08Konversi Tipe Data

python
df_kotor = pd.DataFrame({
    "harga_teks": ["15000", "12.000", "Rp8000", "20000"],
    "tanggal_campur": ["2026-01-05", "06/01/2026", "2026-01-07", "08-01-2026"],
})

# bersihkan teks angka dulu sebelum konversi
df_kotor["harga_bersih"] = (
    df_kotor["harga_teks"].str.replace("Rp", "", regex=False)
    .str.replace(".", "", regex=False)
)
df_kotor["harga_bersih"] = pd.to_numeric(df_kotor["harga_bersih"], errors="coerce")

# to_datetime dengan format campur: coba parsing fleksibel, invalid jadi NaT
df_kotor["tanggal_bersih"] = pd.to_datetime(df_kotor["tanggal_campur"], format="mixed", errors="coerce")

df_kotor["harga_int"] = df_kotor["harga_bersih"].astype("Int64")   # Int64 mendukung NaN, int64 biasa tidak

print(df_kotor.dtypes)
errors="coerce" itu penting

Tanpa errors="coerce", pd.to_numeric/pd.to_datetime akan melempar error dan menghentikan seluruh proses begitu menemukan satu nilai yang tidak bisa dikonversi. Dengan coerce, nilai bermasalah diubah jadi NaN/NaT agar bisa ditangani lebih lanjut dengan teknik di bagian 03-04.

09Encoding Kategorikal: One-Hot Encoding

One-hot encoding mengubah satu kolom kategorikal menjadi beberapa kolom biner (0/1), satu kolom per kategori — cocok untuk kategori tanpa urutan (nominal) seperti nama produk atau kategori toko.

python
df_kategori = pd.DataFrame({"kategori": ["Minuman", "Makanan", "Minuman", "Snack"]})

df_onehot = pd.get_dummies(df_kategori, columns=["kategori"], prefix="kat")
print(df_onehot)
#    kat_Makanan  kat_Minuman  kat_Snack
# 0        False         True      False
# 1         True        False      False
# 2        False         True      False
# 3        False        False       True
Jebakan multikolinearitas

Untuk model linear (regresi linear/logistik), tambahkan drop_first=True pada pd.get_dummies untuk menghindari "dummy variable trap" — satu kategori bisa diprediksi sempurna dari kategori lainnya jika semua kolom dipertahankan.

10Encoding Kategorikal: Label Encoding

Label encoding mengubah tiap kategori menjadi satu angka (0, 1, 2, ...) — cocok untuk kategori yang punya urutan (ordinal) seperti "Rendah/Sedang/Tinggi", atau untuk model berbasis pohon (decision tree, random forest) yang tidak terpengaruh oleh skala angka.

python
from sklearn.preprocessing import LabelEncoder

le = LabelEncoder()
df_kategori["kategori_encoded"] = le.fit_transform(df_kategori["kategori"])

print(df_kategori)
print(dict(zip(le.classes_, le.transform(le.classes_))))
# {'Makanan': 0, 'Minuman': 1, 'Snack': 2}
Hati-hati memakai label encoding untuk kategori nominal

Model linear/regresi bisa salah mengartikan angka hasil label encoding sebagai memiliki urutan/jarak matematis (misal "Snack" dianggap 2x lebih besar dari "Minuman"), padahal kategori nominal tidak punya urutan. Untuk kasus nominal, one-hot encoding (bagian 09) lebih aman.

11Scaling Numerik: StandardScaler vs MinMaxScaler

Scaling menyamakan rentang nilai antar kolom numerik, penting untuk algoritma yang sensitif terhadap skala (misalnya KNN, SVM, regresi dengan regularisasi).

python
from sklearn.preprocessing import StandardScaler, MinMaxScaler
import pandas as pd

df_num = pd.DataFrame({"jumlah": [12, 20, 8, 50, 15], "harga": [15000, 12000, 8000, 25000, 15000]})

standard = StandardScaler()
df_standard = pd.DataFrame(standard.fit_transform(df_num), columns=df_num.columns)
# hasil: mean=0, std=1 di setiap kolom

minmax = MinMaxScaler()
df_minmax = pd.DataFrame(minmax.fit_transform(df_num), columns=df_num.columns)
# hasil: semua nilai berada di rentang 0-1

print(df_standard.describe().loc[["mean", "std"]])
print(df_minmax.describe().loc[["min", "max"]])
ScalerHasilKapan dipakai
StandardScalerMean 0, std 1 (z-score)Data relatif normal, dipakai regresi/SVM/PCA
MinMaxScalerRentang 0-1Perlu rentang pasti (misal input neural network), data tanpa outlier ekstrem
Fit hanya di data training

Panggil .fit() atau .fit_transform() hanya pada data training, lalu pakai .transform() (tanpa fit ulang) untuk data testing — topik ini akan dibahas lebih detail saat split data di Pertemuan 9, untuk mencegah kebocoran informasi (data leakage).

12Pipeline Cleaning Lengkap (Studi Kasus)

Menggabungkan semua teknik di atas menjadi satu alur kerja pembersihan data penjualan UMKM:

python
import pandas as pd
from sklearn.preprocessing import StandardScaler

df = pd.read_csv("data/raw/penjualan_kotor.csv")

# 1. Konversi tipe data
df["harga"] = (df["harga"].astype(str).str.replace("Rp", "", regex=False)
               .str.replace(".", "", regex=False))
df["harga"] = pd.to_numeric(df["harga"], errors="coerce")
df["tanggal"] = pd.to_datetime(df["tanggal"], format="mixed", errors="coerce")

# 2. Tangani missing values
df["jumlah"] = df["jumlah"].fillna(df["jumlah"].median())
df["harga"] = df["harga"].fillna(df["harga"].median())
df = df.dropna(subset=["produk", "tanggal"])   # baris tanpa produk/tanggal valid dibuang

# 3. Hapus duplikat
df = df.drop_duplicates()

# 4. Tangani outlier dengan IQR
Q1, Q3 = df["jumlah"].quantile([0.25, 0.75])
IQR = Q3 - Q1
df = df[(df["jumlah"] >= Q1 - 1.5*IQR) & (df["jumlah"] <= Q3 + 1.5*IQR)]

# 5. Encoding & scaling
df = pd.get_dummies(df, columns=["kategori"], prefix="kat", drop_first=True)
scaler = StandardScaler()
df[["jumlah_scaled", "harga_scaled"]] = scaler.fit_transform(df[["jumlah", "harga"]])

df.to_csv("data/processed/penjualan_bersih.csv", index=False)
print(f"Data bersih: {df.shape[0]} baris, {df.shape[1]} kolom")
Tanda pipeline berhasil

df.isna().sum().sum() bernilai 0, df.duplicated().sum() bernilai 0, dan tidak ada error konversi tipe — artinya dataset siap dipakai untuk tahap eksplorasi (Pertemuan 6) dan modeling (Pertemuan 9).
